# 📊 Employee Data Analysis

A menu-driven **Employee Data Analysis** program built with Python, Pandas, and Matplotlib.

The program allows users to analyze employee information, perform calculations, and generate different types of visualizations directly from an employee dataset.

---

## 🚀 Features

### 👨‍💼 Employee Data
- Display complete employee dataset
- View employee information using Pandas

### 🏢 Department Analysis
- Count employees in each department
- Find department(s) with the most employees
- Calculate average salary by department
- Find department(s) with the highest average salary
- Calculate average performance by department

### 💰 Salary Analysis
- Find the highest salary
- Find the lowest salary
- Calculate average salary
- Find the top 5 highest-paid employees
- Analyze salary distribution

### 📈 Experience Analysis
- Find employee(s) with the most experience
- Find employee(s) with the least experience
- Calculate average experience
- Analyze the relationship between experience and salary

### ⭐ Performance Analysis
- Find highest-performing employee(s)
- Find lowest-performing employee(s)
- Calculate average performance
- Calculate average performance by department
- Find the top 5 performers

### 📊 Data Visualization
The program supports multiple Matplotlib graph types:

- Bar chart
- Horizontal bar chart
- Scatter plot
- Pie chart
- Line plot

### 💾 Export Results
Analysis results and generated visualizations can be exported for further use.
